# 21:9 封面风格库

这套风格库共 9 种，已移除“结构化教程风”。样图均为 21:9，尺寸约为 1916×821。样图用于理解风格，不要求复刻样图中的标题和人物位置。

## 🟠⭐ 暖色手绘教程风

**一句话识别**：奶油纸张 + 手绘图标 + 温暖教程感。

**颜色**：米白、暖棕、珊瑚橙、明黄、浅绿、少量青蓝。

**结构与元素**：可以由真人、标题、浏览器窗口、世界地图、路线箭头、流程图或桌面场景中的任意一项担任主视觉；常用手绘线条、贴纸、涂鸦、荧光笔和柔和阴影。

**适合**：小白教程、方法论、经验分享、Web 出海入门。

**样图**：`assets/style-samples/warm-handdrawn.png`

## 🟢💻 产品主视觉风

**一句话识别**：产品界面或网站截图是核心，真人负责讲解和引导。

**颜色**：浅色或中性色背景，青绿、橙色、黄色作强调。

**结构与元素**：UI、浏览器、产品截图占据主要面积；真人和手势作为辅助；可加入世界地图、流量、用户、收入等少量解释性图标。

**适合**：工具介绍、产品拆解、网站案例、流程展示。

**样图**：`assets/style-samples/product-main.png`

## 🔵⚡ 深色科技爆发风

**一句话识别**：深色空间 + 巨大标题 + 全球网络或发光产品，强调未来感和冲击力。

**颜色**：深蓝、黑色、电光青、珊瑚红、白色。

**结构与元素**：大标题承担主要注意力；人物与浏览器、地球、网络线路形成前后层次；可有少量数字粒子和光线，但不能泛滥。

**适合**：AI 趋势、出海增长、重大教程、强结果主题。

**样图**：`assets/style-samples/dark-tech.png`

## 🟡🟦 撕纸拼贴风

**一句话识别**：撕纸、胶带、照片卡片和手绘箭头组成有层次的内容海报。

**颜色**：米白、黄色、砖红、蓝色、青绿色。

**结构与元素**：标题通常放在最大纸张上；人物、网页截图、世界地图、旅行/出海照片、用户卡片和美元图标分层叠放；强调前景、中景、后景的遮挡关系。

**适合**：出海故事、案例复盘、个人经验、创意型教程。

**样图**：`assets/style-samples/collage.png`

## ⚪🟠 编辑杂志风

**一句话识别**：大量留白 + 大字号标题 + 少量细线和专业图形。

**颜色**：米白、深海军蓝、橙色，少量灰色。

**结构与元素**：标题是主要视觉锤；真人、线稿地球、浏览器轮廓和编号点作为轻量辅助；强调秩序、呼吸感和长文的专业性。

**适合**：万字长文、行业分析、知识整理、深度报告。

**样图**：`assets/style-samples/editorial.png`

## 🟡⚫ 黑金步骤爆款风

**一句话识别**：黑底金字，标题像奖杯一样突出，周围放结果证据。

**颜色**：黑色、金黄、白色，少量暖橙。

**结构与元素**：标题绝对主位；真人位于前景或侧下方；网站、流量图、全球地图、美元硬币以“证据卡片”形式围绕标题，营造高价值和高确定性。

**适合**：从 0 到 1、赚钱结果、步骤型教程、强承诺标题。

**样图**：`assets/style-samples/black-gold.png`

## 🟢⚫ 高饱和实测冲击风

**一句话识别**：荧光绿、紫、红撞色，像“亲自录屏验证”的爆款封面。

**颜色**：黑色、荧光绿、电紫、红色、白色。

**结构与元素**：标题可以倾斜、错位或被色块切割；真人表情和手势更有冲击力；配实测、录屏、真实流程、收款结果等小卡片，搭配浏览器、路径箭头和全球地图。

**适合**：实测、复盘、挑战、工具验证、结果证明。

**样图**：`assets/style-samples/live-test.png`

## 🟡🟥 手写结果承诺风

**一句话识别**：纸张和粗手写字把“学完能得到什么”直接写在脸上。

**颜色**：米白、黑色、红色、荧光黄、暖棕。

**结构与元素**：结果词或收益词用红色突出；黄色荧光笔负责划重点；人物通常生活化出镜；配少量笔记本、电脑、网页、地球和美元线稿，避免信息过载。

**适合**：入门教程、收益预期、经验总结、低门槛行动指南。

**样图**：`assets/style-samples/handwritten-result.png`

## 🟩🌐 产品后台沉浸风

**一句话识别**：深色网站后台铺满背景，真人站在真实工作场景前讲解。

**颜色**：墨绿、黑色、亮绿、白色、黄色。

**结构与元素**：后台仪表盘、流量、用户、收入、日历、网站搭建模块组成信息墙；人物是前景讲解者；标题放在上方并保持足够可读性，强调“系统正在运行”。

**适合**：产品工作流、网站搭建、数据增长、运营系统、出海业务闭环。

**样图**：`assets/style-samples/dashboard.png`

## 使用风格库的规则

风格名只决定视觉语言，不锁死人物位置。每次还要根据用户指定的视觉重点调整主次：

- **标题主视觉**：标题最大最醒目，人物和元素辅助说明。
- **人物主视觉**：人物表情和动作优先，标题围绕人物展开。
- **产品主视觉**：UI、网站或工具界面占主位，人物负责指向和解释。
- **流程主视觉**：用少量箭头、编号和节点讲清楚过程。
- **结果主视觉**：美元、用户、收入、增长等结果元素优先。
- **故事场景主视觉**：用完整场景制造代入感，标题做入口。
